    if you are already on woocommerce3, you should update to woocommerce 3.0.8 and hyyan woocommerce polylang integration 1.1, email translation is working in these versions.

    @romaing you are reporting a different problem, not the same problem

    You need to check Polylang String translation table, WooCommerce emails, see for example: https://github.com/hyyan/woo-poly-integration/wiki/Strings-translations

    Email subject strings can only be translated by po/mo files if you have made no changes in WooCommerce settings.
